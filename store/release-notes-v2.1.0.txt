# 氛圍閱讀 2.1 · 雙頁 PDF 翻譯對照

在右上角按「版面對照」，左邊保留原始 PDF，右邊在對應文字區塊覆蓋譯文，圖表和頁面排版一併保留。

## 新功能與改進
- 段落圖卡／雙頁 PDF 對照可隨時切換，共用同一份翻譯結果。
- 記住最後選擇的閱讀模式，下次開啟其他 PDF 也會沿用。
- 左右頁面同步捲動及縮放，僅為附近頁面配置翻譯畫布，切回圖卡時釋放畫布。
- 雙擊譯文直接在原區塊編輯，失去焦點即儲存；Ctrl／⌘＋Enter 完成，Esc 取消。PDF 與圖卡的修改雙向同步。
- 跨欄／跨頁段落將譯文分配到各實體區塊，手動修改一個區塊不會重排其他區塊。
- 長譯文自動縮小字級，仍放不下時可在區塊內捲動。
- 改善旋轉頁面的文字層對齊，保留短章節標題。
- 「問 AI／翻譯」選取按鈕維持藍底白字，不受主題配色覆蓋。

## 下載
- `vibe-reading-store-v2.1.0.zip`：Chrome／Edge 共用商城上傳套件。手動安裝請解壓縮後「載入未封裝項目」。
- `vibe-reading-brand-v2.1.0.zip`：商城 Logo、完整閱讀人物、雙頁對照與原位編輯截圖、版本說明。
- `checksums-v2.1.0.txt`：上述 ZIP 的 SHA-256 校驗碼。

GitHub Release 與 Chrome／Edge 商城送審分開，這次未代為提交商城。

需要 PDF 本身有可擷取文字；掃描影像尚未提供 OCR。原位編輯保留在目前開啟的文件，重新翻譯會取代修改。此模式用於閱讀顯示，尚未提供翻譯 PDF 匯出。

## 驗證
- 40 項 Node.js 測試通過：包含模式記憶、同步捲動、畫布釋放、跨頁文字、失焦儲存、取消、雙向同步介面、旋轉頁面縮放與摘要語言。
- 瀏覽器以實際 PDF 渲染搭配示範譯文，驗證雙頁排版、原位編輯、切換模式與手機寬度。
- AI 模型輸出使用既有翻譯引擎；本次功能驗證未重新下載及測試裝置上的所有模型。
