# 氛圍閱讀 2.0 · Vibe Reading

這次更新把閱讀介面、PDF 縮放和品牌形象一起整理成第二版。

## 更新內容
- 新的「頭、臉、書」簡化 Logo；完整閱讀人物保留在 README。
- 炭黑、橘黑、粉黑三款暗色配色，工具列、翻譯圖卡、設定與浮動面板同步切換並記憶設定。
- 狀態／進度整合至標題列，翻譯完成後自動隱藏；翻譯中以彩色轉球顯示。作者咖啡入口位於右上角。
- PDF 縮放改為依手勢幅度調整、每幀合併更新；只補畫可見及附近頁面，取消過期重繪，使用完成後換圖以減少閃白，並限制高倍率畫素配置。
- 摘要跟隨目標語言，加入逐欄語言檢查與翻譯回退；切換語言不再讓舊摘要覆蓋新結果。
- 預設開啟 PDF 暗色模式，保留既有使用者記住的開關選擇。

## 下載檔案
- vibe-reading-store-v2.0.0.zip：Chrome／Edge 擴充功能套件；手動安裝請解壓縮後「載入未封裝項目」。商城上傳也使用此套件。
- vibe-reading-brand-v2.0.0.zip：Chrome 128×128 Logo、Edge 300×300 Logo、512px 共用 Logo、完整閱讀人物主視覺與發布文案。

GitHub Release 與 Chrome／Edge 商城審核、更新時程分開；本次只發布 GitHub Release，商城請另外提交。

## 驗證
- Node.js 內建測試：21 項通過（摘要語言、舊請求保護、縮放錨點、過期渲染取消、附近頁面補畫與畫素上限）。
- Edge 摘要回退已以模擬 API 回歸驗證；不同裝置上的實際模型輸出仍可能有差異。

所有 AI 推理維持在本機執行；首次使用仍可能需要下載模型／語言包。
