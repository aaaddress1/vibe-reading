# opencc-js

`core.js` is `dist/esm-lib/core.js` from [opencc-js](https://github.com/nk2028/opencc-js)
1.4.2 (MIT, see `LICENSE`).

`s2twp.json` holds the OpenCC dictionaries for Simplified → Traditional
(Taiwan, with Taiwanese phrasing): `STPhrases`, `STPhrases_GeneratedFromRegionalPhrases`,
`STCharacters`, `TWPhrases`, `TWVariantsPhrases`, `TWVariants`, as the dictionary
groups `ConverterFactory()` takes. The data comes from
[opencc-data](https://github.com/nk2028/opencc-data) via opencc-js and is under the
Apache License 2.0 (see `LICENSE-dict-Apache-2.0.txt`).
